# Burger Hand Tracking Game

## Deskripsi

Game simulasi pembuatan burger sederhana yang menggunakan Hand Landmark Detection dari MediaPipe Unity Plugin sebagai input utama.

## Kontrol

* Pinch (Thumb + Index bersentuhan): Mengambil dan memindahkan objek.
* Lepas Pinch: Menjatuhkan objek.

## Cara Bermain

1. Ambil patty menggunakan gesture pinch.
2. Masukkan patty ke area grill hingga matang.
3. Pindahkan seluruh bahan ke area burger.
4. Setelah semua bahan lengkap, burger akan dibuat secara otomatis.
5. Pindahkan burger ke area konfirmasi.
6. Burger akan ditukar menjadi uang.

## Menjalankan Project

1. Buka project menggunakan Unity.
2. Buka scene:
   Assets/SceneDone.unity
3. Tekan Play.

## Teknologi

* Unity
* MediaPipeUnityPlugin
* Hand Landmark Detection
